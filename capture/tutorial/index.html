Missing a language? How to add more voices to this device
macOS: System Settings → Accessibility → Spoken Content → System Voice → Manage Voices → download the needed language.
Windows: Settings → Time & Language → Speech → Manage voices → Add voices.
Android: Settings → System → Languages & input → Text-to-speech output → Google TTS → Install voice data.
iOS/iPadOS: Settings → Accessibility → Spoken Content → Voices → download the needed language.
Once installed at the OS level, the browser picks it up automatically — no changes needed here.
